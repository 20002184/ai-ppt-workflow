# v2 风格候选

## A：科研答辩风（推荐）

- 适合：医学 AI、算法流程、真实病例和审稿式汇报
- 视觉：浅底、深蓝主色、青绿强调、少量橙色警示
- 后端：混合模式；文字和数据原生，封面/章节页可用生成视觉
- 优点：可信、可读、可编辑
- 风险：需要强制控制版式节奏，否则会退化成普通模板

## B：手绘技术解释风

- 适合：解释复杂算法、让非专业听众理解流程
- 视觉：手绘线条、纸张纹理、局部示意图
- 后端：概念页整页图片，证据页原生图表
- 优点：亲和、有记忆点
- 风险：医学技术汇报中可能削弱严谨感；生成图中文字容易出错

## C：数据仪表盘风

- 适合：工程状态、批处理结果、指标监控
- 视觉：深色背景、指标区、状态颜色、密集数据
- 后端：原生图表 + 局部图片
- 优点：适合展示字段和运行状态
- 风险：容易造成“系统已临床验证”的错觉，不适合作为整套主风格

### 当前建议

选 A 作为主风格，借用 B 的局部解释性插画，保留 C 的状态标签但不使用大面积 dashboard 卡片。
