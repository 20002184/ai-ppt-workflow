# 质量评分表

每个维度 0–5 分，最终分数不是简单平均；任何高风险事实错误或关键页面不可读都直接阻止交付。

| 维度 | 5 分标准 | 0–2 分信号 |
|---|---|---|
| 叙事 | 每页推进同一主线，结论先行 | 只是把文档标题拆成页面 |
| 内容忠实 | 所有数字、术语、边界可追溯 | 生成模型补写结果或机制 |
| 图文关系 | 图直接解释本页主张 | 图只是装饰或与文字冲突 |
| 版式 | 页面角色有节奏，信息密度适中 | 连续重复卡片模板 |
| 字体可读 | 投影距离可读，无溢出，颜色/字号/粗细/对齐与源图一致 | 小字、截断、混乱换行、颜色或字重漂移 |
| 素材质量 | 原图清晰、来源明确、比例正确 | 模糊、变形、来源不明 |
| 可编辑性 | 需编辑部分可编辑 | 所有内容被烘焙成图片但未说明 |
| 动画/视频 | 有明确叙事作用且能稳定播放 | 为动而动或播放失败 |
| 讲稿 | 备注能支撑口头表达 | 只有重复页面文字 |
| 可复现 | 后端、提示词、素材和状态可追踪 | 只能靠聊天重做 |

## 缺陷分级

- High：事实错误、医学图像被改变、关键文字截断、核心页面不可读、素材缺失。
- Medium：节奏单一、标题弱、图文关系松、来源不明显、备注无用。
- Low：对齐、颜色、留白或非关键字体细节。

交付门槛：High=0；Medium 逐项记录并说明是否接受；Low 可进入复盘清单。

## 可编辑文字视觉硬门槛

图片转可编辑 PPT 时，“能编辑”不能抵消视觉属性变化。每个可读前景文字都必须同时满足：

- 使用源图像素框和阅读顺序；字号由字高与整行宽度联合校准，不能被自动 fit 静默缩小。
- 颜色从原始字形像素估计，分别处理浅底深字和深底浅字。
- 保留常规/粗体层级、对齐、行距和垂直锚点。
- 公式、关键词、状态、指标卡等混合颜色/字体内容拆成原生 runs 或独立文本框。
- 预览必须加载真实字体并按源图有效像素密度渲染；预览中出现缺字、截断、变暗、变浅、变小、变粗或错位即失败。
- 复杂医学图像仍可作为独立图片资产，但其可读文字必须从底图清理后重建为原生文本，不能声称复杂插图已经变成可编辑矢量。

v6 交付前必须运行 `python v6/visual_fidelity_gate.py`。该门控逐页检查源图字形证据、颜色候选、字号来源、字体文件、文字框边界、预览文字存在性、source/preview mask 重叠和重复框；门控失败即禁止交付。
