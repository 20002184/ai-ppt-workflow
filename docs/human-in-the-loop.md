# 人工介入清单

## 必须人工确认

1. 听众、场景、时长、页数和汇报目的。
2. 关键结论是否忠实于原始文档，尤其是医学、统计和临床表述。
3. 哪些图片必须原样插入，哪些视觉允许生成或重绘。
4. 视觉风格、可编辑性目标和生图后端。
5. 第一张样张是否达到可继续扩展的标准。
6. 真实病例、实验结果、统计数字和来源标记。
7. 最终投影可读性、动画节奏、音视频播放和隐私合规。

## 可以自动化

- Word/PDF 结构抽取；
- 标题和术语一致性；
- 页数、文件、媒体和备注检查；
- 文本框越界、空白页、重复页标题；
- 图片分辨率、宽高比和来源清单；
- 任务状态和生成后端记录；
- 演讲稿初稿和页面过渡句。

## 不应完全自动化

- 把“无候选”写成“临床阴性”；
- 重绘真实医学图像或实验数据；
- 选择可能误导的装饰性图片；
- 在没有确认的情况下改变主题、页数或视觉方向；
- 把视觉模型生成的文字当作事实来源；
- 以“PPTX 能打开”替代演示质量验收。
